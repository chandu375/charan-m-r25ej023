Write a 2d graphics editor using * and  _.

Write functions to draw a circle, rectangle, line, and triangle.
You should be able to
      add objects to the picture,
      delete objects from the picture, and
       modify objects in the picture.
Use a 2d array of characters to store the picture.
Write a function to display the picture.

Design and implement a simple 2D Graphics Editor using C/C++. Represent the drawing area using a 2D array of characters, where _ denotes an empty pixel and * denotes a drawn pixel.

Implement functions to:

Draw a line.
Draw a rectangle.
Draw a triangle.
Draw a circle.

The editor should support the following operations:

Add objects (line, rectangle, triangle, circle) to the picture.
Delete existing objects from the picture.
Modify the properties of existing objects.
Display the current picture on the screen.

Store all graphical objects and redraw the picture whenever an object is added, deleted, or modified. Use appropriate data structures and functions to manage the objects and maintain the drawing canvas.
