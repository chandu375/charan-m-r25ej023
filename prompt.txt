Write a complete C program for a 2D Graphics Editor using '*' and '_' characters.

Problem Statement:
Write a 2D Graphics Editor using '*' and '_'.

Requirements:
1. Use a 2D character array as the canvas.
2. Implement functions to draw:
   - Line (using Bresenham's Line Algorithm)
   - Rectangle
   - Circle (using Midpoint Circle Algorithm)
   - Triangle
3. Create a Shape structure and ShapeType enumeration.
4. Store all objects in an array of structures.
5. Each object must have a unique ID.
6. Implement the following operations:
   - Add Object
   - Delete Object
   - Modify Object
   - Display Picture
7. When an object is deleted or modified, redraw the entire canvas.
8. Use a menu-driven interface.
9. Define constants:
   - ROWS = 30
   - COLS = 60
   - MAX_OBJECTS = 100
10. Display the canvas inside a bordered frame.
11. Include proper comments and modular functions.
12. Use only standard C libraries: stdio.h, stdlib.h, and math.h.
13. Store the picture in a 2D character array.
14. Allow multiple objects to exist on the canvas simultaneously.
15. The program should be suitable for a C Programming/Data Structures mini-project.
